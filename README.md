# شعر و تال غفور

یک اپ وب راست‌به‌چپ برای GitHub Pages با رنگ‌بندی سرمه‌ای، سفید و طلایی.

## اجرای محلی
فایل `index.html` را در مرورگر باز کنید. برای ذخیره فایل‌های رسانه‌ای، مرورگر باید از IndexedDB پشتیبانی کند.

## نشر در GitHub Pages
1. تمام محتویات این پوشه را در ریشه یک repository آپلود کنید.
2. در Settings → Pages، گزینه Deploy from a branch را انتخاب کنید.
3. شاخه `main` و پوشه `/(root)` را انتخاب و Save کنید.
4. لینک GitHub Pages را در Safari آیفون باز کنید و از Share → Add to Home Screen استفاده کنید.

## نکته مهم درباره پخش پس‌زمینه
برنامه از کنترل‌های استاندارد صوتی مرورگر استفاده می‌کند. ادامه پخش پس از رفتن به برنامه دیگر یا قفل‌کردن آیفون به نسخه iOS، Safari، نوع فایل و سیاست‌های سیستم وابسته است و از یک وب‌اپ معمولی GitHub Pages نمی‌توان آن را تضمین کرد. برای اطمینان کامل از پخش پس‌زمینه، اپ بومی iOS لازم است.

## اطلاعات و فایل‌ها
متن‌ها و تنظیمات در حافظه مرورگر ذخیره می‌شوند؛ رسانه‌ها در IndexedDB همان مرورگر ذخیره می‌شوند. پاک‌کردن داده‌های Safari ممکن است اطلاعات محلی را حذف کند. از بخش تنظیمات برای پشتیبان‌گیری متن‌ها و فهرست‌ها استفاده کنید. فایل‌های رسانه‌ای داخل پشتیبان JSON گنجانده نمی‌شوند و باید جداگانه نگهداری شوند.
